# Slop patterns (supplement)

Impeccable's own anti-pattern list is the primary source: read it from the installed package (`impeccable detect`, plus the "absolute bans" in its `craft-floor.md`). This file only adds tells to look for by eye in screenshots and code. Do not copy Impeccable's list here.

- Purple-to-blue gradients; cyan on dark; gradient text.
- Glassmorphism (blur + translucent panels) used everywhere instead of one place with a reason.
- Identical icon-heading-text card grids; a rounded-square icon tile above or beside every heading.
- Uniform rounded corners with the same soft shadow on every surface.
- Emoji used as icons.
- Centered hero with two buttons.
- One generic accent color used for everything (status, links, decoration, buttons alike).
- Cramped or uniform spacing with no grouping rhythm.
- Bouncy, looping or infinite animations; motion on every element.
- Low-contrast gray text, especially tiny uppercase tracked labels.
- Shouty all-caps badges and labels on ordinary status.

For each finding record the file and line (or screenshot name) and whether it is resolved, or intentionally kept with a reason.
